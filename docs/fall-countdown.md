# 종강 카운트다운 로직 정리

## 구현 위치
- `src/app/page.jsx`: 홈에서 `CountdownTimer`를 렌더링하며, 이번 학기 종강일(`FALL_TERM_END`)을 넘겨준다.
- `src/components/countdown-timer.jsx`: 남은 시간 계산, 메시지 선택, UI 렌더링을 담당한다. 다음 학기 일정(`NEXT_TERM_DATE`, `NEXT_TERM_LABEL`)과 막판 메시지 맵(`FINAL_SPRINT_MESSAGES`)도 여기에서 정의된다.

## 동작 흐름
1) `calculate(target)`로 목표 시점까지 남은 일/시간/분/초를 계산해 `{ days, hours, minutes, seconds, finished }` 형태로 반환한다.  
2) `useEffect`로 1초마다 현재 시각을 다시 계산해 종강 카운트다운(`timeLeft`)과 다음 학기 카운트다운(`nextTermLeft`)을 갱신한다.  
3) 메시지 선택 로직:
   - 이미 종강했으면: `방학입니다! 다음 학기(...)까지 ... 남았어요.` 메시지로 전환하고 UI 타이틀도 방학 모드로 바뀐다.
   - 남은 일수 ≤ 13일: `FINAL_SPRINT_MESSAGES`에서 해당 일수 키(0~13)를 찾아 노출.
   - 남은 일수 ≥ 30일: `"아직 한 달 남짓!..."`
   - 남은 일수 ≥ 15일: `"중반전 돌입!..."`
4) 화면에는 남은 시간(`formatDuration`)과 위에서 결정한 메시지가 함께 노출된다.

## 막판 멘트 매핑(0~13일)
| 남은 일수 | 메시지 요약 |
| --- | --- |
| 13 | 알고리즘 복습 리스트 정리 |
| 12 | 네트워크 계층 복습 + 로그 백업 |
| 11 | OS 스케줄링 정리·일정 공유 |
| 10 | 자료구조 리팩터링 + 노트 |
| 9 | DB ERD 재점검 + 코멘트 처리 |
| 8 | 캡스톤 발표 슬라이드 보강 |
| 7 | 종강 D-7, 코테 감각 유지 |
| 6 | 보안/해킹 레포트 점검 |
| 5 | README/포트폴리오 업데이트 |
| 4 | AI 팀플 로그/그래프 정리 |
| 3 | 컴파일러처럼 남은 과제 정적 분석 |
| 2 | CI/CD 한 번 더 돌리고 공유 |
| 1 | 종강 전야, 마지막 코드 리뷰 |
| 0 | 방학 ON, 잘 쉬는 것도 스킬 |

## 커스터마이징 가이드
- 종강일 변경: `src/app/page.jsx`의 `FALL_TERM_END`를 수정해 카운트다운 대상 날짜를 바꾼다.
- 다음 학기 일정 변경: `src/components/countdown-timer.jsx`의 `NEXT_TERM_DATE`/`NEXT_TERM_LABEL`을 수정한다.
- 메시지 수정: 같은 파일의 `FINAL_SPRINT_MESSAGES`에서 0~13 키에 원하는 문구를 넣으면 해당 일수에 맞춰 교체된다. 30일 이상·15~29일 구간 메시지도 같은 파일의 조건문에서 조정 가능하다.
